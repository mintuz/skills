# Preserve meaning

Compress the words, never the meaning: the shorter version must support the same conclusions as the source, and no stronger ones.

1. Before compressing, list what changes how the source should be understood: each condition, exception, branch, causal link, dependency, scope limit, uncertainty, value with its unit, identifier and warning.
2. Cut repetition, filler and phrasing. Keep every listed item. If the target length cannot hold them, exceed it and say so; never drop one silently.
3. Keep uncertainty at its original strength. "Probably" stays probable, "unconfirmed" stays unconfirmed, and an open question stays open. A diagram keeps every branch, including failure and exception paths, and marks unverified ones as unverified.
4. Add nothing the source does not contain. Attribute its claims and actions to the source rather than presenting them as new conclusions. Then compare the result with the source item by item.

Distinct from: `principle-lead-with-the-answer` (ordering your own answer or report), `principle-label-the-evidence` (marking the status of new claims), `principle-state-the-scope` (restating a broad request before work).

Done: no meaning-changing detail is lost or added; each condition, branch and hedge survives at its original strength.
