# Judge with fresh eyes

Whoever built the work does not give its acceptance verdict.

1. When a quality or acceptance verdict is due, hand it to a context that did not build the work: a fresh agent, a separate reviewer or a different model. Give it the bar, the artifact and the inventory of what changed or was delivered, not the builder's rationale, drafts or conclusions.
2. Report the builder's own passing checks as supporting evidence, not as the verdict.
3. When no independent context is available, run a clean review pass yourself. Start from the inventory and the bar, examine each item as delivered, and set the drafting rationale aside. State in the verdict that the builder judged its own work.
4. Keep routine self-verification while building, such as compiling or running tests between steps, with the builder. This principle governs the verdict, not every check.

Distinct from: `principle-fix-the-bar-first` (setting criteria before evaluation), `principle-prove-it-works` (the builder's direct check of a result), `principle-scale-verification` (choosing which checks to run).

Done: the verdict comes from a non-builder context; or a clean review pass from the inventory was run and the limitation is stated.
