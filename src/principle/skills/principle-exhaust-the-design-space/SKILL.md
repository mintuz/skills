# Exhaust the design space

Explore the uncertainty that could change the decision, rather than enumerating every imaginable design.

1. State the user outcome, constraints and unresolved decision. Reuse established precedent when it already settles the choice.
2. Build two or three materially different, inexpensive alternatives when the uncertainty warrants it. For an interaction, prototype enough to judge feel; for architecture, exercise the disputed contract or path.
3. Compare the same representative cases side by side, including relevant failure, accessibility, lifecycle and maintenance costs. Name what each alternative gives up.
4. Select using observed evidence and constraints. Record the remaining uncertainty and the cheapest check that could change the choice.

A supplied, accepted label or styling change can proceed directly with proportional verification. Prototype permission authorizes exploration, not production replacement.

Distinct from: `principle-redesign-from-first-principles` (a new requirement challenges an existing design), `principle-experience-first` (journey or scope trade-offs grounded in the observed product), `principle-fix-the-bar-first` (fixing selection criteria before evaluating candidates).

Done: the choice has a defensible comparison, or existing evidence makes alternatives unnecessary. Label prototype findings separately from implemented or runtime-proven behavior.
