# Guard the context window

Keep the active question small and preserve enough evidence to resume accurately.

1. Scope the current phase and its stopping condition. Search filenames and symbols first, then read bounded excerpts or filtered logs; avoid repeatedly loading full payloads.
2. Keep conclusions with source locators and the observations that support them. Distinguish facts, rejected hypotheses, decisions and unresolved questions.
3. Discover the host's available tools. Use scoped searches and local summaries when sufficient. Delegation is optional and requires appropriate authorization and capabilities; it is not a prerequisite for managing context.
4. Before continuity is at risk, save a concise durable handover in an allowed location: accepted goal and scope, current artifact/branch identity, completed changes, exact checks and outcomes, remaining uncertainty, and the next executable step.
5. On resumption, read that handover and refresh state that could have changed. Preserve evidence pointers instead of copying raw private logs into every summary.

Done: another context can continue without redoing the investigation or mistaking a plan, static check or unavailable runtime check for completed proof.
