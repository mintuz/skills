# Resume

Pick up a session that crashed or stopped, for example "continue, my device crashed". The prior trail is the input: rebuild its state, re-check its claims, and continue from the resume point. Do not start the task again.

1. **Locate the prior trail.** Use `recall` to find the prior session and its linked branch, worktree and PR; `recall` owns where history lives. When the transcript is long, give it to a delegate, and keep only the timeline that it returns: the goal, the playbook, the plan, the decisions, the open todos, the last action and each "done" or "passed" claim (principle-guard-the-context-window). Done: a timeline with a locator for each item.
2. **Rebuild the live state.** Follow principle-refresh-before-resuming. Record the branch, its base and the dirty work. Run `git log <base>..HEAD` and `git diff <base>...HEAD` to see what landed. When the run used worktrees, run `bash scripts/worktree.sh status <run-id>`, then check each unit worktree for commits and uncommitted changes. Check the PR and its CI when one exists. Done: each unit is marked integrated, committed but not integrated, uncommitted, or not started.
3. **Re-check each inherited claim.** For each "done" or "passed" claim in the timeline, run its check again on the current head of the real artifact (principle-prove-it-works). A prior self-report is history, not proof. Mark a claim that you cannot re-check as unknown, and name the check that would settle it. Done: each claim is confirmed, refuted or unknown.
4. **Name the resume point.** Compare the plan with the live state. Keep each unit and each finding that step 3 confirmed: do not implement it again, and do not repeat its diagnosis. Done: one sentence, "Resume at step <n> of <playbook>: <next action>".
5. **Restore the todo list.** Copy the steps of the routed playbook. Mark each finished step done, with its evidence from steps 2 and 3.
6. **Continue in the routed playbook.** Keep the coordinator role. For a unit worktree that holds unfinished work, give a fresh agent the original brief, the timeline and that worktree path. "Continue" is a session grant (Autonomy in the SKILL.md): finish without checkpoints.
7. **Reply.** State where the prior session stopped, what you inherited, what you re-checked, what you redid and why, the resume point and the outcome.
