# Sharpen

Make the user's task deeper, not bigger. Do not start the task: the output is the analysis below plus the rewritten prompt.

1. Say what a top professional in this field would do here that the user did not ask for.
2. Name the rawest material they would start from instead of what has already been digested for the user.
3. Name the specific methods and tools they would use.
4. Say what independent evidence, other than you or the user, would show the result is right.
5. Rewrite the user's prompt to ask for exactly that. Leave decisions that belong to the user open as explicit questions or placeholders instead of deciding them.
