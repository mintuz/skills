# teach evaluation

Behavioral scenarios plus invocation and exclusion checks. The `prechange/SKILL.md` snapshot records the pinned upstream entrypoint before portability changes for RED provenance. Treatment reads the live source skill. Trigger fixtures are disposable copies refreshed by the repository runner. Scenario-only evaluation does not establish operational or cross-harness replay.

Behavioral prompts run in `workspace/`; trigger discovery runs in `trigger-workspace/` to keep no-skill comparisons free of generated skill copies. `results.json` is gitignored local output recording per-case responses and grader reasons; verbose local logs and generated fixtures are ignored.
